# PRD: CSV 요약 CLI

## 개요
CSV 파일을 읽어 지정한 숫자 컬럼의 합계를 계산하는 CLI 도구의 요구사항을 정리한다.

## 사용자 및 환경
- 사용자: 데이터 분석가, 운영 담당자 (US-01, US-02 참조)
- 환경: Windows 11, Python 3.11, 터미널에서 실행

## 사용자 스토리
- [PRD-U001] (US-01): 사용자는 CSV 파일 경로를 전달하면 열의 합계를 바로 확인하고 싶다.
- [PRD-U002] (US-02): 사용자는 계산할 컬럼을 지정해 결과를 정확히 제어하고 싶다.

### 수용 기준
- [PRD-A001]: 숫자 컬럼의 합계를 계산해 표준 출력에 한 줄로 표시하고 종료 코드 0을 반환한다.
- [PRD-A002]: 존재하지 않는 파일 경로를 받으면 오류 메시지를 출력하고 종료 코드 1을 반환한다.

## 기능 요구사항
- [PRD-F001] (F-01): CSV 파일을 읽어 행과 열을 파싱한다.
- [PRD-F002] (F-02): 지정한 숫자 컬럼의 합계를 계산한다.

## 비기능 요구사항
- [PRD-N001] (NF-01): 잘못된 입력에 대해 원인을 식별할 수 있는 오류 메시지를 출력한다.

## 범위 외
- 웹 UI 제공
- 대용량 병렬 처리
- 외부 DB 연동
