# SRS: CSV 요약 CLI

## 개요
CSV 파일에서 숫자 데이터를 집계하는 CLI의 소프트웨어 요구사항을 정의한다.

## 범위
입력 검증, CSV 파싱, 합계 계산, 결과 출력, 오류 처리를 포함한다.

## 정의 및 약어
- CSV: 쉼표로 구분된 값 파일
- CLI: Command Line Interface

## 참조 문서
- docs/1.Concept/PRD.md
- docs/3.Design/SDD.md

## 전체 설명
시스템은 CSV 파일 경로와 컬럼명을 입력으로 받아 해당 컬럼의 합계를 계산하고
표준 출력으로 반환한다. 실패 시 종료 코드로 성공과 실패를 구분한다.

## 기능 요구사항

[SRS-F001]
CSV 파일 경로를 받아 파일을 읽고 행과 열로 파싱한다.
상위요건: [PRD-F001]

[SRS-F002]
지정한 컬럼명의 숫자 값을 합산해 합계를 반환한다.
상위요건: [PRD-F002]

## 비기능 요구사항

[SRS-N001]
파일이 존재하지 않으면 경로를 포함한 오류 메시지를 출력하고 종료 코드 1을 반환한다.
상위요건: [PRD-N001]

## 인터페이스 요구사항
CLI 인터페이스는 `summarize <파일경로> <컬럼명>` 형태로 인자를 받는다.
결과는 표준 출력에 한 줄로 출력한다.

## 제약사항
- Python 3.11 이상에서 동작한다.
- 외부 네트워크 접근을 하지 않는다.

## 부록
샘플 입력 파일은 첫 행을 헤더로 간주한다.
